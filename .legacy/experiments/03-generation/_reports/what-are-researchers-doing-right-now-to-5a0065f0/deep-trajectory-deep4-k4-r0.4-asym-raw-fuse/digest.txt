DEEP CRITIQUES (full-text peer review of key papers):
arXiv:2005.14165:
NOVELTY: Scaling to 175B parameters to enable "in-context learning," allowing task adaptation via text prompts without gradient updates or fine-tuning.
STRENGTHS: Demonstrates significant performance gains across benchmarks, such as 86.4% accuracy on LAMBADA (few-shot) and 20.50 perplexity on PTB.
WEAKNESSES: Increases computational demands through massive parameter counts and large context windows; admits potential data contamination in training sets.
RELEVANCE: Counter-productive; the paper advocates for massive scaling to achieve task-agnosticism, which inherently makes inference slower and more expensive.
arXiv:2309.06180:
NOVELTY: Introduces PagedAttention, an attention algorithm that manages KV cache using non-contiguous blocks (inspired by OS virtual memory paging) to enable fine-grained memory sharing and near-zero fragmentation.

STRENGTHS: Achieves 2–4× throughput improvement over state-of-the-art systems (FasterTransformer, Orca) by enabling higher batch sizes through efficient memory utilization.

WEAKNESSES: The paper does not explicitly quantify the computational overhead/latency penalty introduced by the PagedAttention kernel's non-contiguous memory access patterns compared to standard contiguous kernels.

RELEVANCE: Directly addresses the "faster and cheaper" requirement by optimizing GPU memory capacity, allowing more concurrent requests (higher throughput) per hardware unit.
arXiv:2602.22090:
NOVELTY: Employs a dual-metric confidence strategy—combining $P(T)$ (token probability) and $P(IK)$ (a trained MLP classifier using hidden states)—to dynamically escalate queries through a hierarchy of LLMs.
STRENGTHS: Demonstrates significant efficiency gains, including a 60% reduction in GPT-4o token usage and a 36.46% reduction in computational cost for 8B $\to$ 70B LLaMA models, while maintaining comparable accuracy.
WEAKNESSES: The $P(IK)$ classifier relies on supervised training on specific datasets, and the multi-stage escalation process may increase end-to-end latency and cause error propagation in long chains.
RELEVANCE: Directly addresses the question by presenting a "model cascading" framework that optimizes the trade-off between model scale, accuracy, and computational expense.
arXiv:2604.22906:
NOVELTY: Shifts the focus from homogeneous cloud-centric or single-device paradigms to the heterogeneous, wireless-constrained network edge, specifically addressing the interplay between LLM statefulness (KV cache) and time-varying wireless channels.
STRENGTHS: Provides a robust taxonomy of four collaborative architectures (Table 1) and identifies the "two-phase asymmetry" (compute-bound prefill vs. memory-bound decoding) as a fundamental driver for edge-specific optimization.
WEAKNESSES: Highlights that advanced strategies, such as Hybrid Collaborative Inference, introduce extreme orchestration and state-management complexity that may undermine latency gains in high-mobility or unreliable-link environments.
RELEVANCE: Directly categorizes current research efforts into three actionable pillars: model compression (quantization/pruning), architectural partitioning (vertical/horizontal), and cross-layer resource management.
