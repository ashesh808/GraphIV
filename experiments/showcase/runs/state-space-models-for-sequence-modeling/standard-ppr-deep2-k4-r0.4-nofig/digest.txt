arXiv:2111.00396:
NOVELTY: Introduces the Structured State Space (S4) model using a Normal Plus Low-Rank (NPLR) parameterization of the state matrix $A$, enabling stable diagonalization and efficient computation via a Cauchy kernel.
STRENGTHS: Solves the 16k-length Path-X task (88% accuracy) where all prior models failed, and achieves 60× faster generation than Transformers on WikiText-103.
WEAKNESSES: Susceptible to numerical instability if $A$ has eigenvalues in the right half-plane; ablation studies indicate performance is driven primarily by HiPPO initialization rather than the NPLR parameterization itself.
RELEVANCE: Provides an $O(N+L)$ complexity framework that unifies continuous, recurrent, and convolutional representations to handle extremely long-range dependencies across multiple modalities.
arXiv:2601.09495:
NOVELTY: Introduces Memory Recurrent Units (MRUs) and the Bistable Memory Recurrent Unit (BMRU), which use multistability to achieve persistent (infinite-duration) memory while remaining parallelizable via associative scans.

STRENGTHS: Demonstrates superior long-term dependency retention in the "copy-first-input" benchmark, where BMRU maintains low MSE across sequence lengths up to $10^5$ while LRUs fail.

WEAKNESSES: The BMRU relies on non-differentiable Heaviside and sign functions, necessitating surrogate gradients; the paper lacks a rigorous analysis of how the choice of $\alpha_{surr}$ affects convergence or training stability.

RELEVANCE: Proposes a hybrid architectural approach (combining BMRU with SSMs) to resolve the fundamental trade-off between the parallelizable fading memory of SSMs and the persistent memory of nonlinear RNNs.
