# Literature Review: Large Language Model Agents and Tool Use

The evolution of Large Language Model (LLM) agents and their ability to utilize external tools has progressed from foundational transformer architectures to sophisticated, multi-agent collaborative systems capable of autonomous reasoning and real-world interaction.

## Origins: Foundations of Language Modeling and Early Interaction (2017–2020)

The lineage of modern LLM agents begins with the introduction of the Transformer architecture in arXiv:1706.03762, which established the backbone for subsequent language modeling advancements. This was followed by the development of bidirectional representations in BERT (arXiv:1810.04805), which utilized pre-training on unlabeled text and fine-tuning to achieve high performance on benchmarks like GLUE and SQuAD.

As models grew, the focus shifted toward task-agnostic capabilities. The emergence of few-shot learning via text interaction in arXiv:2005.14165 demonstrated that models could perform tasks such as arithmetic and translation without gradient updates, relying instead on on-the-fly autoregressive reasoning. This era also saw the first significant steps toward tool integration through Retrieval-Augmented Generation (RAG) in arXiv:2005.11401, which combined parametric knowledge with a non-parametric dense vector index of Wikipedia to enhance knowledge-intensive NLP tasks. Simultaneously, early embodied agent research, such as the BUTLER agent in ALFWorld (arXiv:2010.03768), began exploring the alignment of text-based policies with visually grounded actions in simulated environments.

## Key Advances: Reasoning, Planning, and Tool Integration (2021–2022)

The period between 2021 and 2022 marked a transition from simple text completion to structured reasoning and active tool use.

### Reasoning Mechanisms
A major breakthrough occurred with Chain-of-Thought (CoT) prompting (arXiv:2201.11903), which elicited intermediate reasoning steps for arithmetic and symbolic tasks. This was further refined by "Self-Consistency" (arXiv:2203.11171), which improved CoT performance by sampling multiple reasoning paths and selecting the most consistent answer. Other advancements included "Zero-shot CoT" (arXiv:2205.11916), which used the prompt "Let's think step by step," and the "Tree of Thoughts" (ToT) framework (arXiv:2305.10601), which generalized CoT by exploring coherent units of text through multiple reasoning paths, including look-ahead and backtracking.

### Tool Use and Programmatic Reasoning
Researchers began offloading computation to external tools to overcome model limitations. Program-Aided Language models (PAL) (arXiv:2211.10435) and Program of Thoughts (PoT) (arXiv:2211.12588) utilized Python interpreters to execute code generated by the LLM, effectively disentangling reasoning from computation. Similarly, TALM (arXiv:2205.12255) introduced an iterative "self-play" technique to bootstrap performance using non-differentiable APIs.

### Embodied and Web-Based Agents
Agentic behavior extended into specialized environments. WebGPT (arXiv:2112.09332) utilized imitation learning and rejection sampling to enable browser-assisted question answering. In robotics, models were used as high-level planners to propose natural language actions constrained by pretrained low-level skills (arXiv:2204.01691), while "Inner Monologue" (arXiv:2207.05608) introduced closed-loop language feedback to allow agents to process environment descriptions for better planning.

## Current Frontier: Autonomous Agents and Multi-Agent Systems (2023–2025)

The current landscape is defined by highly autonomous agents that can teach themselves to use tools, engage in complex planning, and collaborate in multi-agent societies.

### Self-Supervised Tool Learning
A significant shift toward autonomy is seen in Toolformer (arXiv:2302.04761), which uses self-supervised training to decide when and how to call APIs (e.g., calculators, search engines). This concept of self-improvement is echoed in the Self-Instruct framework (arXiv:2212.10588), which bootstraps models using self-generated instructions. More recently, ToolLLM (arXiv:2307.16789) has enabled models to master over 16,000 real-world RESTful APIs through instruction fine-tuning on the ToolBench dataset.

### Advanced Agent Architectures
Modern agentic frameworks now incorporate sophisticated cognitive architectures. The Generative Agents architecture (arXiv:2304.03442) uses a three-part system (observation, planning, and reflection) to simulate human-like social behavior. Reflexion (arXiv:2303.11366) introduces verbal reinforcement learning, where agents use linguistic feedback and episodic memory to improve performance without weight updates. For complex problem solving, the Tree of Thoughts (ToT) and Graph of Thoughts (GoT) (arXiv:2308.09687) models allow for more deliberate, non-linear reasoning.

### Multi-Agent Collaboration
The frontier has also moved toward "societies" of agents. MetaGPT (arXiv:2308.00352) uses a multi-agent framework with Standardized Operating Procedures (SOPs) for software engineering, while AutoGen (arXiv:2308.08155) enables customizable, conversable agents. Other frameworks like CAMEL (arXiv:2303.17760) use role-playing to explore communicative settings, and Multi-Agent Debate (arXiv:2305.14325) uses iterative discussion to improve factuality and reasoning.

### Emergent Reasoning via Reinforcement Learning
Most recently, DeepSeek-R1 (arXiv:2501.12948) has demonstrated that pure reinforcement learning can incentivize emergent reasoning patterns, such as self-reflection and dynamic strategy adaptation, without the need for human-labeled reasoning trajectories.

## Tensions and Open Problems

The literature reveals several critical tensions:
* **Reasoning vs. Execution:** While CoT and ToT improve reasoning, there is ongoing debate regarding the efficiency of these methods compared to programmatic approaches like PAL (arXiv:2211.10435) or the necessity of explicit planning (arXiv:2302.01560).
* **Tool Generalization:** There is a tension between models trained on specific API sets (e.g., Toolformer) and the need for generalist agents capable of zero-shot tool use in massive, evolving ecosystems (e.g., Gorilla, arXiv:2305.15334).
* **Complexity vs. Reliability:** While multi-agent systems (MetaGPT, AutoGen) offer higher capabilities, they face challenges in maintaining consistency and avoiding "hallucinations" during long-horizon tasks, a problem addressed by frameworks like Reflexion and ChatEval.
