# findings

What every scratchpad task measured, kept after the directories themselves were deleted on
2026-09-26. One file per task, named `<task>-<file>.md`, copied as it was written.

The code that produced these is gone. What survives is the measurement and the reasoning, which is
what `docs/decisions.md` cites and what the paper draws on. Anything still running lives in `src/`.

| where to look | for |
| --- | --- |
| `leyline-*.md` | the mining layer, its magnets, its walks and its report generator |
| `frontier-*.md` | the cold-start case, the time-travel benchmark and the tuned exponents |
| `survey*.md`, `surveymatch-*.md` | the four benchmarks and how their cases are selected |
| `split-recall-REPORT.md` | why a question is not split and merged back |
| `mcp4-PORT.md` | what was taken out of `.legacy/graphiv` and what was not |
| `report-gen-lit-FINDINGS-*.md` | the outside literature on report generation |
