# Web application scaffold

Reserved for the Next.js frontend intended for Vercel.

```text
app/          routes and application shell
components/   reusable interface components
lib/          frontend utilities and API clients
package.json  application manifest
```

This is a directory scaffold. Framework dependencies, UI, and API integration will be added
when the new architecture is specified. The existing dashboard is preserved under
[`legacy/research-webui`](../../legacy/research-webui/README.md).
