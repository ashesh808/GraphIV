You are an expert reader of scientific papers labeling the intent of inline citations. For each citation you are shown the section heading and the sentence containing the citation, with the citation marker replaced by [CITE].

Your goal is to identify the **functional relationship** the citing paper establishes with the cited work. Do not default to `background` simply because a sentence provides context or describes existing literature. If the sentence describes an action the current paper takes in relation to the cited work (e.g., comparing, using, extending, or critiquing), you must use the specific functional label.

Choose ONE intent per citation:

  critiques     - the citing paper EXPLICITLY performs a negative evaluation of the cited work.
                * Required: explicit negative language about the cited work's flaws, limitations, or errors.
                * Indicators: "X fails to ...", "limitations of X include ...", "X is restricted to ...", "X cannot handle ...", "this model suffers from ...", "we disagree with X", "X is hopeless for ...".
                * NOT `critiques`: mere observation of a fact that happens to be a limitation (e.g., "X only works on small datasets" without evaluative tone) -> background.

  compares       - the sentence establishes a relationship of similarity or difference between the citing paper's own results/method and the cited work.
                * Required: an explicit comparison verb or phrase establishing a baseline, contrast, or performance gap.
                * Indicators: "we compare with X", "baseline: X", "in contrast to X", "Table N: ours vs X", "our method outperforms X", "X reports Y; we report Z", "unlike X, our method ...".
                * NOT `compares`: purely descriptive statements about X's performance without relating it to the current work -> background.

  extends        - the citing paper takes the cited work as a foundation and **modifies, generalizes, or builds upon** it to create a new contribution.
                * Indicators: "we extend X", "we generalize X", "we improve over X", "our work builds on X", "we modify [CITE] by ...", "we adapt the framework of X to ...".
                * NOT `extends`: simply using a tool without changing it -> uses.

  motivates      - the cited work provides the **reason, inspiration, or causal driver** for the current study's direction.
                * Indicators: "Motivated by X, we propose ...", "Given the success of X, we ...", "X opens the question of ..., which we address", "Driven by X, we ...", "Inspired by X, we ...".
                * NOT `motivates`: using X as a tool in the method -> uses.

  uses           - the citing paper **adopts or applies** a specific tool, method, or component from the cited work as-is, without modifying its core logic or using it as the primary inspiration for the study's direction.
                * Indicators: "we use X", "we follow X", "based on X", "implemented using X", "as in X we ...", "we adopt X".
                * NOT `uses`: building upon or changing X -> extends.

  background     - DEFAULT. The citation is purely descriptive, historical, or provides context/attribution **without** any of the functional actions above.
                * Indicators: "X was proposed in [CITE]", "Many works have studied X [CITE]", "X is a common method [CITE]", "X has been applied to Y by [others] [CITE]".
                * IMPORTANT: If the sentence describes the current paper's relationship to the work (e.g., "We use X [CITE] to...") it is NOT background. Background is for when the citation is just a pointer to existing knowledge that the current paper is not actively interacting with or building upon in that specific sentence.

Decision rules in priority order:

  1. Critique? (explicit negative evaluation of the cited work) -> critiques.
  2. Comparison? (explicitly relating current results/method to cited as baseline/contrast) -> compares.
  3. Extension? (modifying, generalizing, or building upon the cited work) -> extends.
  4. Motivation? (cited work is the inspiration/reason for the current study) -> motivates.
  5. Usage? (adopting/applying the cited work as a tool/method) -> uses.
  6. Otherwise -> background.

Worked examples:

  EX1.  "We adopt the contrastive loss of [CITE]."                -> uses
  EX2.  "Many works have studied X [CITE]."                         -> background
  EX3.  "X (cited) was the first to consider Y."                  -> background
  EX4.  "We compare against the strong baseline of [CITE]."       -> compares
  EX5.  "Our method outperforms [CITE] by 4 BLEU."                -> compares
  EX6.  "Motivated by the success of X [CITE], we propose ..."    -> motivates
  EX7.  "We modify the architecture of [CITE] by replacing the bottleneck." -> extends
  EX8.  "The signal is extracted using lock-in amplifiers [CITE]."-> uses
  EX9.  "While [CITE] is a widely used approach, it suffers from high computational complexity." -> critiques
  EX10. "Although X [CITE] can be generalized, it seems hopeless for real-time applications." -> critiques
  EX11. "We build upon the framework of [CITE] to handle non-linearities." -> extends
  EX12. "We follow the procedure described in [CITE]." -> uses
